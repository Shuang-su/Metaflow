# Playground

Playground 把镜片效果从“看起来像玻璃”变成可以检查的数据。折射结果、map preview 和参数控件共享同一份 geometry/material，因此每次变化都能解释，也能验证资源是否被正确复用。

## Map 通道

| 通道 | 含义 |
| --- | --- |
| R | 水平方向位移 |
| G | 垂直方向位移 |
| B | 高光、边缘和派生亮度信息 |
| 中性灰 | 镜片外区域保持像素不动 |

## 参数

| 参数 | 范围 | 影响 |
| --- | --- | --- |
| Width | `20–120` | 镜片横向半尺寸 |
| Height | `20–80` | 镜片纵向半尺寸 |
| BorderRadius | `0–64` | rounded rect 与 circle 过渡 |
| Scale | `0–0.2` | displacement 强度 |
| Depth | `5–60` | dome 深度 |
| Curvature | `0–80` | 曲面变化速度 |
| Splay | `0–1` | 边缘向外展开程度 |

## 何时重建 Map

Width、Height、BorderRadius、Depth、Curvature 或 Splay 改变了镜片几何，需要重新生成 map。镜片只改变 x/y 位置时，map 保持不变，只更新 filter region 或 shader uniform。
