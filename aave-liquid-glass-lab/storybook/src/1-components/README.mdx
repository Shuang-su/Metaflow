# 组件案例

这一组页面研究 Liquid Glass 如何成为真实界面组件的一部分。每个案例都保留原始 Aave 组件的运行逻辑，并在演示之后说明折射目标、状态变化、代码实现和浏览器边界。

## 共同结构

DOM 组件虽然形态不同，但都遵循相同的运行契约：

1. 正常渲染可访问、可交互的真实控件。
2. 单独准备需要被折射的 `refraction target`。
3. 使用 lens geometry 生成 displacement map。
4. 只把 SVG filter 限制在镜片和 bleed 覆盖的紧凑区域。
5. 位置变化只移动 filter region；形状变化才重建 map。

## 交互与可访问性

玻璃层不是输入状态的来源。Switch 保留 native checkbox，Slider 保留 native range，Toggle 保留真实按钮和键盘焦点；视觉复制层不接收指针事件。这样既能维持语义，也能避免 glass overlay 抢占交互。

## 性能基线

- map 与 source texture 分开管理，不能在每一帧重复生成不变资源。
- filter bbox 应贴合镜片，而不是覆盖整块页面。
- resize 必须同步 CSS 尺寸、drawing buffer、viewport 和 lens 坐标。
- 验收必须包含实际状态变化和像素签名，不能只检查元素是否存在。
