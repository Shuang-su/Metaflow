# Web Liquid Glass：原理与实现

这是一份面向 Web 设计与工程人员的实现研究册。它以 Aave 的公开文章和本地保存的运行证据为研究起点，解释液态玻璃如何在普通 DOM、Canvas 与 Video 表面上产生一致的折射行为。

<ReadmeHero />

## 研究目标

这里关注的不是一层透明背景或模糊滤镜，而是一套可以复现、测量和验证的像素位移系统：

- 镜片几何如何变成 displacement map。
- 普通 DOM 如何通过 SVG filter 折射真实内容。
- Canvas 和 Video 为什么必须进入 WebGL texture 管线。
- 同一套镜片参数如何跨 Chromium、Safari 与 Firefox 工作。
- 组件移动、形变和交互时，哪些数据需要更新，哪些资源必须复用。

## 核心结论

Web Liquid Glass 的核心输入是一张按镜片几何生成的 displacement map。中性区域保持像素不动，红绿通道描述水平与垂直位移，额外通道和派生数据用于色散、边缘高光与亮度修正。

| 表面 | 正式路径 | 研究册案例 |
| --- | --- | --- |
| 普通 DOM | SVG `feImage`、`feColorMatrix`、`feDisplacementMap` | Hero、Switch、Slider、Segmented Toggle |
| Canvas | source/map/blur textures + WebGL shader | QR Code |
| Video | live video texture + 多镜片 WebGL renderer | Video Controls |

## 跨浏览器边界

<div className="winner-table">

| 实现路径 | Chromium | Safari | Firefox |
| --- | --- | --- | --- |
| SVG `backdrop-filter` | ✓ | ✕ | ✕ |
| HTML-in-Canvas API | 需开启实验 flag | ✕ | ✕ |
| Generated displacement map | ✓ | ✓ | ✓ |

</div>

Safari 上完整效果成立，是因为最终实现没有依赖 Chromium 独有的 SVG `backdrop-filter` 或 HTML-in-Canvas，而是让 DOM 使用 SVG displacement、Canvas 与 Video 使用 WebGL。Safari 还需要限制 filter region、刷新 filter 标识，并避免直接过滤 live video。
