## 原生运动、表面与路线

原版Viewer仍是唯一运动来源。只读物理状态提供tick/epoch、实际位置、接地、支撑和有效碰撞；导航不写人物位置，不采用渲染插值判定。固定2m、接地经过12个60Hz tick到达，无标记视线或停稳要求；查询无总时限、会话无重试次数上限。

目录区分稳定surface ID、确认楼层和transition连接面。实际归属依赖上一表面、原生支撑和有效邻接；跳跃中断地面链，唯一合法落地重新关联。暂停/恢复携带同tick/epoch支撑。路线裁剪、局部接续、全局重规划及重复经过相同表面均重建有顺序的表面段，不能按全场最近点跨层跳进度。没有确认目录时不以半米高度分桶或地图手动选层伪造关联。

单文件/分块输入均复用原碰撞查询和坐标变换；清单绑定每文件hash、覆盖和范围。分块几何边界不产生虚假封墙，缺块不是空地。目录portal必须有真实几何边界和双向通行证据；合成错层、叠层、宽portal、跳跃落地、暂停恢复和路线分段已覆盖。
