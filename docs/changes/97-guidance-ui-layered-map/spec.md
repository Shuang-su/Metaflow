# MF-97 Spec — 导览标识、分层地图与地面分析

状态：实施中，本地试用；不发布、不部署。Issue：[MF-97](https://github.com/Shuang-su/Metaflow/issues/97)。

2026-10-09 增补授权：正常推送 `codex/mf97-navigation`，在 Mac Studio 轻量续作。代码、只读场景、派生缓存和工具环境分开；迁移完成与真实多层导览完成分别验收。`main`、原实验工作树和 Livecho 项目保持原状。

## 基础与范围

从 Viewer 5.20.1 `ed7c4cb8` 隔离，迁入 MF-79 `2d15ab27`；Studio 编辑源码以 MF-58 `5aa9af46` 只读快照为基础。原版 CameraManager/WalkController 是唯一运动来源，导航和显示不得改变输入或物理结果。保留 Recast、持续查询、无总查询时限、无会话重试上限、高斯遮挡的完整剩余路线；无光点、自动行走、AI 和完整插件系统。

用户修正：媒体峰会上层未采集，不验证其跨层；大运作为首选多层资产，华发冰雪世界作为未上线本地候选。未上线资产不得加入公开资源入口。

## UI 与标识资格

顶部标题始终可打开列表。导览开启时列出可导览目的地，前后切换保持原 sourceIndex；关闭恢复全部标点查看。原公开 selectAnnotation 语义不变。导览中普通标识只展示内容，保留相机和目的地；到达内容同样不移动相机。

内建 @Nav 声明只读取 extras.metaflow.nav.enabled 的 boolean true，且要求有效保存相机。标题/正文无命令解析。未声明为普通标识；明确声明但相机无效的标识保留展示并说明原因。Studio 合并该字段而不损坏未知 extras，通过原撤销/草稿/保存/导出链。67 点在试用副本显式启用，原工程只读。Studio 仍遵守既有 camera 必需的公共格式，缺相机文件明确拒绝并保持输入；不可导览资格的 UI 检查不宣称放开该格式。

导览和小地图独立开关，使用既有设置样式并保存偏好；导览默认关，具地图资产小地图默认开。到达固定水平 2m、同一合法地面局部区域、接地 12 个连续 60Hz tick（0.2s）；忽略旧 3m 偏好，不要求 LOS 或停稳。

导览开启时附近目的地最多 3 个含当前目标，其他限同层、12m；只影响显示，不影响资格/路线。目标不受距离限制。关闭恢复原显示。导览图标代替满屏数字，标题悬停/选中显示；键盘、触控及地图交互不传给人物。

## 地图与层

独立离线 PlayCanvas app 正交俯视，以世界高度过滤高斯（不能用 near/far 冒充切层），关闭开场。逐瓦片等待真实流式 LOD、工作缓冲、排序和稳定 frame:ready，输出 WebP+sidecar。缓存记录 Gaussian/collision 源、变换、世界范围、切片、层与瓦片哈希及覆盖状态。未知/缺块不能报告全层完成。

Viewer 只加载底图并叠加位置、朝向、当前层路线/目标。跟随/全程、拖动缩放独立于规划。查看其他层不改变物理归属/到达；底图缺失独立说明而不显示成寻路失败。层、表面和连接身份稳定并绑定资产，使用原生支撑、上次关联与相邻拓扑；相机高度只作参考。

## 地面分析与审查

Open3D 0.19.0 detect_planar_patches 为离线拟合工具。全覆盖、多高度表面、8m 核心块+1.04m halo 串行。保护墙、侧面、洞口、楼板边界及踏步；初始候选不超过一个源体素（8cm）。不确定真实矮台阶与噪声时不自动改，不补大洞/楼梯/未知。

稀疏候选记录来源、残差、结构保护与前后差异；可逐片接受/拒绝/回退。仅通过结构与原生行走核验的 patch 可用于新试用碰撞，并从同一碰撞重建导航。原高斯不变，路线仍仅高斯遮挡。楼梯/坡道经双向原生行走再连接，禁止跨层吸附/宽松参数补通。

## 验收边界

保留固定20、旧7、全部67的分母；2m 范围复跑既有成功路线不得退化。包含普通/Nav/缺相机/未知扩展保存往返与 UI；地图坐标/接缝/高度/缺块；微凸凹、8/16/24cm踏步、坡、墙脚、展台、叠层、洞口。30/60/120Hz+jitter同一物理状态误差≤1cm，内容只触发一次；真实浏览器/自动回放/用户验收区分。用户批准续作仍使用外置 Prism，临时保留≥5GiB，累计新增8GiB上限不变。每批按目标卷余量、临时产物及恢复记录估算；不足保存恢复状态，不缩覆盖/删分母。关键实景、多层或全场分析未完成时仍为试用。

## 续作接口与原件边界

续作基线为 `3b8ba998`。派生产物使用独立 `continuation-20261002/`，旧472块报告复制后重筛，不覆盖旧结果；迁移只能剔除旧修改，不增造新修改。原始碰撞、模型与标点保持只读。

导航输入适配单文件与分块碰撞，绑定源、变换与真实已知覆盖。运行时使用显式楼层/表面/连接目录；半米高度桶只作分析辅助。原生物理步后旁路关联表面，楼梯/坡道为连接面；路线裁剪与维护同步更新表面分段。大运优先验证一个原生双向正常步行连接，LOD0局部地图须明确范围，不能声明全场完成。华发仅本地配准/资料核验，未确认轴向、尺度及可用导航输入前不接入公开资源。

地面审查增加独立高斯剖面对照。接受决定、材料化碰撞及同源导航绑定指纹；原生行走验证前不可切换试用源。CPU占用叠加不代表GPU碰撞已经更新。原件与修正版成套切回。

## Mac Studio 迁移约定

采用部分克隆、稀疏检出与仓库本地 LFS skip-smudge，不展开 `data`、不全量下载 LFS、不默认浅克隆。配置入口为 `MF_ASSET_CONFIG`，默认 `.codex-work/config/assets.local.json`，绝对路径只保存在本机忽略文件。场景可按 URL 前缀挂载已有目录；浏览器 URL、Studio 格式、坐标与导航行为不变。原文件及源哈希匹配时复用，否则明确缺失、版本不同或需要重建。

仅按清单搬迁派生导航、地图、地面报告与大运索引，逐文件 SHA-256 校验；依赖、Python 环境、Studio 构建与截图不搬迁。旧报告和试用包身份不改写，输入位置可解析但旧验证不能被称为新设备验收。试用包定位后需重新形成证明和新包身份。

Node 固定 22.23.3 原生 arm64，下载匹配官方 SHA-256；四个目录独立按 lockfile 安装。Open3D 固定 0.19.0，在新机器的独立 Python 环境安装。Mac Studio 配置先单重任务，Node heap 至多 32 GiB、进程树 RSS 至多 64 GiB，且依据实测内存限制在一半之内；继续分块、原子写出和中断恢复。远端产物新增额度初始 8 GiB，目标卷预留 20 GiB；本机续作仍用授权的 5 GiB/1.5 GiB 配置。transform 的具体工具版本、输入、参数随作业固定，不自动升级。

迁移验收要求 GitHub/两台机器 SHA 一致、无旧机器依赖链接、资源清单匹配、真实查询与一块大运导航及真实 detector 可运行；67 点/固定20/旧7、浏览器导览及修正版切回另行复验。远端路径、内存、磁盘、网络和依赖未实测时不得宣布迁移完成。
