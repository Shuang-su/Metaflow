右下圆钮表示下一种自动模式。手动平移或缩放后，左下定位钮恢复此前模式，随后淡出。地图支持鼠标和双指锚定缩放、越界阻尼与回弹，并响应减少动态效果。工具栏在地图与操作示意、设置、信息间同步切换。

三点把手同时支持拖动和窗口菜单。地图可放大到工具栏和进度条上方的可用区域，缩小后恢复浮窗原位置。最小化与工具栏收起共用状态。地图补面和场外空白统一采用现场道路采样灰，保留测绘墙线及台阶。封面为同机位 4096 × 4096 静态无损 WebP。新增兼容地址 `/shenzhen/nanhaiyiku` 并保留查询参数。
