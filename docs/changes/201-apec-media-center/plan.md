## 源码与静态资源

1. 在实际 5.25.1 发布链的独立分支构建相同 Viewer 的 5.25.2 兼容资源入口。
2. 从正式母版衍生公开 LOD、地图、封面、原生碰撞和可核对的区域。将资源放在独立路径，逐个验证大小写、字节数与 SHA-256。
