- 常用/漫游设置分页；旧本机偏好兼容，速度 0.75/1.5/2.25 m/s、45/90/120°/s，默认 1.5/90；弧线/直线持久化。关闭菜单等待回中。
- 有碰撞控制器舒适模式默认弧线；首表面遮挡、完整足迹和净空、经过分块连续覆盖检查；最多 128 段、每段不超过 0.2m、2秒及头部水平10m上限。路径检查不改变流式加载中心。
- 青色落点环、红叉、琥珀未知区域及文本原因；近手柄的未知区域提示保持可读距离。无碰撞不生成落地点。预览最多30Hz，提交始终用当前位姿重新查询；缓冲复用。
- 回起点先完整验证再改位置与朝向；失败保持原位并转入原因面板。最后一个手柄断开，即使手部输入仍在也显示恢复面板。此两项延续 #70 的恢复契约。
- 保留真实头部追踪、20cm名义间隙及2.5cm容差、引擎与资源格式。未改变 WebGPU XR 能力判断。

以上为实现者自查，不是独立审查。
