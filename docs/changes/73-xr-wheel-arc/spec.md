# MF-73：单右手柄轮盘与弧线瞬移

Accepted / Draft；实现完成，真机验收待完成。基于 MF-70；唯一 Plan 为用户在 [Codex](codex://threads/01a09044-33de-7380-a80d-fb37c20f5f8b) 确认的《MetaFlow：单右手柄优先的沉浸漫游体验升级》。Issue #73，分支 codex/xr-wheel-arc；不发布生产。

## 操作契约
应用菜单键切换固定在头前 1.2m、直径 0.45m 的四向轮盘，上继续／右模式／下完整设置／左回起点，中心取消；摇杆原始力度 <0.25 回中，>0.55 选向，45°边界外加8°稳定区；扳机按下与提交同项才执行。唤出者独占，旧扳机释放和摇杆回中后启用，失踪取消。完整面板保留射线入口，分常用操作和漫游设置。关闭菜单后等待回中。失败动作保持原位并显示原因。

速度默认保持1.5m/s、90°/s，可选0.75/1.5/2.25m/s与45/90/120°/s，舒适转向仍30°。本机偏好向后兼容。既有20cm名义间隙和2.5cm高度容差不变。

## 瞬移契约
有碰撞手柄舒适模式默认弧线，可切直线；手势保留直线。初速6m/s、向下9.8m/s²、最长2秒、水平10m、每段≤0.2m、≤128段。首个表面决定遮挡，经过的分块必须已加载；不因瞄准改变碰撞加载中心。保留严格足迹、坡度与胶囊净空验证。青色合法、红叉拒绝、琥珀未加载，伴随原因文本。无碰撞不生成落地点。

预览≤30Hz、复用缓冲，软件位移／转向、姿态、输入与会话变化使缓存失效；确认用当前射线重新查询。预览和确认同查询，保持头部真实追踪与当前朝向。
