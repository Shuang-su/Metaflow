## 契约
仅 collisionStatus=unavailable 使用渲染场景拾取；loading及未知碰撞块不能绕过校验。独立世界射线查询相机，复用Viewer高斯深度拾取，不覆盖XR眼睛或头部位姿。

观察目标≤头部10m，目标前停靠0.75m，不自动转头、加速或惯性。舒适模式select重新查询后瞬移；连续模式selectstart定目标，保持时靠近、松开立刻停。控制器沿用速度，手部0.75m/s；辅助向前走为互斥选项。未命中/近距离/过期不动，不展示可站立环或防穿墙保证。

预览≤10Hz，同一时刻一个GPU查询；提交等预览完成后新查。每次源/会话/菜单切换丢弃旧代次结果，复用缓冲。查询开销单独记录，不改头显分辨率。

## 验收
地面墙面高处、范围/近距离、异步取消与菜单抢占、未知分块、双眼与拾取耗时。普通Viewer选点/飞行不变。PICO三场景各10分钟、同路线录屏和真实帧时间，未完成保持实验状态。无公开格式/引擎/资产生成/自动画质变化，不合并发布。
