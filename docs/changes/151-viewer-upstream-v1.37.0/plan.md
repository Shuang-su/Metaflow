# 同步 SuperSplat Viewer v1.37.0，发布 Metaflow 5.22.0

Accepted 2026-10-18. [Issue #151](https://github.com/Shuang-su/Metaflow/issues/151) / [唯一 Spec](spec.md) / [实际验证](verification.md).

## 目标与已确认选择

以当前生产 **5.21.11、100 项资源、schema 1.2** 为基线，将 Viewer 上游从 **v1.35.2** 同步至 **v1.37.0 / `cd0e316e397929ffa87abd4833f73f8a0bd1fd2b`**，PlayCanvas 固定为 **2.23.0**。纳入 XR、标注、调试层和构建修复，保留 Metaflow 的加载、品牌、分析及资源兼容行为。[上游发布说明](https://github.com/playcanvas/supersplat-viewer/releases/tag/v1.37.0)

已确认：

- XR 双手移动、旋转、缩放作用于**主体与环境整体**，退出后恢复原始摆放。
- 随机渲染器**默认关闭**，通过显式实验参数开启；4K 截图继续使用现有排序渲染路径，完成或失败后恢复随机预览。
- 本计划沿用上一轮完成标准：候选验证通过后正式发布，并完成回读、15 分钟观察和本地主线同步。

## 实施内容

- **隔离与来源记录：**从实施时的最新 `origin/main` 建立升级分支，优先复用现有干净隔离工作区；创建升级 Issue、唯一 Spec 和 Plan，通过 PR 合入。保护本地研究历史及冻结的发布暂存。上游分块体素 PR #328 尚未合入，本轮不将其作为稳定版能力导入。
- **引擎与构建：**升级 Viewer 的 PlayCanvas 与必要构建依赖，保留 Node 20.19.0。同步上游开发监听修复；替换已失效的 `drawTexture` 调用，验证深度拾取、体素叠加、方向及销毁清理。Director 和 Editor 保持各自现有依赖与发布产物。
- **XR：**采用朝向计算、后处理恢复、AR 天空隐藏、独立头显预算及距离 LOD 策略；保留现有双摇杆移动、平滑转向和 WebGL 回退。创建实例内场景根节点承载主体和环境，迟到的环境也加入同一变换。双手抓取期间暂停摇杆和传送，释放后恢复；进入前保存、退出或失败后恢复场景、相机、裁剪面、渲染和性能状态。
- **XR 辅助显示：**标注锚点和调试几何保持与场景变换一致；XR 期间暂停桌面标注的相机跳转，退出后恢复。碰撞数据保留原始坐标，不新增 XR 体素行走机制。独立头显的点预算只约束可选择 LOD 的场景，不抽稀单体 SOG。
- **标注与品牌：**采用相机接近目标后显示面板、环绕后保持选中及定位修复。保留官方独立／组合 Logo、展开动画、九语言，以及透明加载界面、上方百分比和下方阶段详情。
- **随机渲染：**纳入上游实验实现及后续修复，保持 WebGPU 显式启用、WebGL／XR 回退。截图事务同步切换渲染与拾取，使用排序路径输出原有 RGBA 格式；成功、异常和销毁均清理临时状态，恢复预览时重新建立累积历史。

## 接口与兼容边界

- 新增与上游一致的可选实例及页面参数：`stochastic`、`splatSource`、`variant`；默认行为不变，不增加普通用户设置开关。
- `createViewer`、`renderViewerHtml`、现有包导出及独立页面全局接口保持兼容；Node 侧 HTML/settings 导入不加载图形引擎。
- `captureFrame` 保留尺寸、时间、超采样、RGBA 返回、首帧等待、串行请求和失败恢复契约，不新增随机截图质量参数。
- 保留 Safari 模块／索引恢复、分块读取进度、图片先于 UI、主体与环境并行加载、渐进显现、单体／分块体素及历史 settings 兼容。
- 100 项资源的 ID、路由、别名、模型、settings、环境、体素和封面保持原值；只更新发布版本信息。

## 验证与验收

- **工程与数据：**类型、lint、格式、单元测试、生产构建、包校验和相关 CI；100 项索引／settings／实体文件验证及资源哈希对照。
- **加载与浏览器：**Chromium WebGL／WebGPU、WebKit WebGL、原生 macOS Safari；桌面和手机画幅覆盖大运、笔架山、缇宝、芒种及主体加环境场景。验证慢请求、短暂失败、重试、终止失败、迟到环境与缺失体素，保留现有行为断言。
- **渲染与截图：**检查黑底／渐变／环境、初始镜头、后处理、标注遮挡和调试层；验证 4096² 截图、并发截图、注入失败、截图后继续交互，以及随机预览与排序截图往返恢复。
- **XR 与生命周期：**覆盖完整朝向、VR／AR 进入退出、整体抓取、迟到环境、相机及变换恢复、双摇杆兼容、权限失败、反复创建销毁和加载中销毁。无实体头显时明确记录未完成硬件验收，不以模拟结果替代。
- **性能：**同设备、同镜头、同缓存条件，对普通 SOG、主体加环境和大型 LOD 各做三轮配对测量，记录首帧、交互帧耗时、驻留分块及显存。新的可复现明显回退先定位解决；上轮接受的内存增量不自动延伸为本轮接受。随机渲染单独报告性能与画质，不用于掩盖默认路径回退。

## 发布、空间与回退

- 项目卷计划时约剩 **1.4 GiB**。实施前估算实际增量，复用现有浏览器缓存和已验证资源，通过 APFS 写时复制或只读硬链接避免整批复制；空间不足时报告缺口，不自动删除研究、源资产或发布证据。
- 验收通过后更新 **5.22.0**、Viewer Ledger、Version History 及上游来源记录；正常 squash 合并产品 PR，回填最终产品 SHA，再创建 `viewer-v5.22.0` 和 GitHub Release。
- 完整候选部署保留既有资源、Editor 与 Director；验证后提升生产，回读实际部署 ID、版本、构建 SHA、代表路由、资源和分析请求，观察至少 **15 分钟**。
- 实施前重新核验回退目标；当前为 **5.21.11 / `6aca09261511aa373989bac4`**。阻断性加载、路由或核心交互回归触发回退并追加记录。
- 生产确认后普通合并远端结果回本地 `main`，保留研究提交。交付 PR、产品与构建 SHA、tag、部署 ID、验证／未验证项、性能对照和观察结果。
