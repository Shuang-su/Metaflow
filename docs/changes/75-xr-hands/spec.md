## 契约
默认真实 local-floor 高度，旧posture不再自动启用1.65m补高。显式坐姿增高需二次确认，只移动rig；参考空间reset清空输入，要求重新校准碰撞地面。

菜单三页。默认直接确认，悬停0.8/1/1.5s含200ms等待，100ms同目标边缘暂停，200ms移开重启。面板右侧确认区≥约2°，超距离不计时；文字高亮不等于提交。直接选择与悬停共用输入所有权。回起点/增高/校准/退出独立确认页。轮盘不悬停；移动不悬停。

默认右手选择、左掌心入口，35°保持300ms出现、50°消失；可以交换主手，单手保留空间入口。掌心不直接执行动作。浏览器select优先，不擅自模拟关节捏合；瞬态输入的正常移除不触发断连。

主动操作自动接管，旧输入释放/回中，不额外确认；源出现不抢占。遮挡/隐藏/断连取消旧操作和软件移动，恢复必须新操作。局部诊断无原始手轨迹上传。
