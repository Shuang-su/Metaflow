# MF-165 桌面高斯人像原型 Spec

状态：Implementation / isolated experiment。主任务：[MF-165](https://github.com/Shuang-su/Metaflow/issues/165)，共享研究：[MF-147](https://github.com/Shuang-su/Metaflow/issues/147)。

## 目标与边界

让真实 PLY/SOG 高斯人像在倾斜平板中呈现与水平桌面相连的单观察点透视。首轮交付是 `metaflow-viewer/experiments/desktop-portrait/` 下独立运行的实验，不进入生产构建，不改变 Viewer 公共 API、默认相机、资源索引或版本。

参考为 [Parapeek Clock 官方几何说明](https://www.doui-lab.com/en/apps/parapeek-clock/)；只独立实现几何原理，不复制其代码、模型、图片或品牌。固定渲染依赖与当前 Viewer 一致：PlayCanvas 2.23.0。

## 坐标与投影契约

- 屏幕空间：x 向右，y 向上，z 朝观察者；可见画布中心为原点，单位为米。物理宽 W 由用户测量输入，高 H = W × canvasHeight / canvasWidth。
- 眼位 E=(ex, ey, ez)，ez 必须为正。相机实体位于 E，朝向保持沿 -Z，不 lookAt 屏幕中心。
- 垂直 FOV = 2 atan(H / (2ez))；aspect = W/H；projectionOffset=(-2ex/W, -2ey/H)。通过 PlayCanvas setter 更新偏移，同时更新相机实体与焦距，让渲染/排序/裁剪读取同一状态。
- 倾角 α 是屏幕相对水平桌面的夹角。桌面根节点位于屏幕下沿 (0,-H/2,0)，绕 X 旋转 90°−α；其 +Y 为竖直、-Z 向桌面后方。
- 人像脚底、地面、软接触阴影共享桌面根节点。阴影是可关闭的视觉辅助，不能称为真实测量光照。
- resize 不偷换物理尺度：重新计算 H，提示复核可见画布的物理宽与观看位置。

## 首轮可观察行为

1. 默认显示清楚标注的几何校准物；本地导入单个 PLY/SOG 后切换为真实高斯渲染，不上传文件。可加载用户明确输入的 HTTPS 同类资产 URL。
2. 提供画布宽、倾角、眼位 XYZ、人物高度、人物深度、人物朝向、源模型上下翻转与地面样式/颜色。数值有限且限幅；错误可恢复。
3. 提供屏幕平面校准标记、手动模拟眼位、重置、全屏/隐藏控制与退出展示。
4. 可选前摄追踪，仅在点击后请求 video、audio=false；MediaPipe 模型与运行时固定版本。单目追踪以用户当前眼位及中性脸尺寸校准相对运动；不把归一化 landmark z 当作米制深度。限幅、平滑，长丢脸/明显突变后回到手动校准位并要求显式重新居中。首轮假设单人环境；当前 `numFaces:1` 不能可靠识别持续同框时的换人，正式产品需补多脸暂停与目标连续性验收。
5. 摄像头关闭、隐藏页面、pagehide/销毁时停止 tracks、调度与 detector。权限拒绝/推理失败显示错误并回到手动模式。没有任何上传摄像头、关键点或轨迹的代码，也不加载产品分析/回放模块。
6. 可选倾角读取经显式按钮与平台权限；首轮只辅助 pitch，横竖屏重映射或不可用时明确退回手动。传感器不是头部位置输入。
7. 默认不保存用户文件、脸信息或远程资源 URL。校准参数可以在本次页面会话内使用。

## 验收与未覆盖

- 数学测试：多组眼位的屏幕四角与中心 NDC 不变；前/后景视差方向正确；不同倾角下脚点共面、桌面 up 正确；无效输入被拒绝或限幅。
- 浏览器：WebGL2 实际启动、加载一个真实高斯文件、控制生效、错误与重试、窄屏布局、全屏降级；记录 console 错误。
- 摄像头：使用测试视频/测试替身验证权限拒绝、启停竞争、隐藏与释放，不冒充真人跟踪准确率。
- 尚待目标 iPad 实机完成光学贴合、低光/眼镜/头动准确率、持续运行温升与帧时间；尚待生产 Viewer 控制权、XR、截图、WebGPU/streamed LOD 集成。首轮完成不关闭产品 Issue。

## 扩展方向：花店 VRM 数字人与桌面空间（已实现基础集成，对话待接入）

2026-11-13 用户提出结合此前花店网站的数字人/模型。已找回并核实来源：[LAPLACE Persona 的 Milky Green / 明前奶绿 VRM 1.0](https://laplace.live/persona/vrm)；对话部分为 [Eidolon](https://laplace.live/eidolon)。

**当前实现状态**（2026-11-13）：VRM 1.0 角色加载、待机动画、眨眼、注视和测试音频驱动口型已实现并通过 48 项自动化测试。实时对话接入留作后续扩展。

### 产品与架构

- 同一桌面展示底座支持高斯展品与三维角色。优先实现 VRM 1.0 角色站在桌面上，原地待机、呼吸、眨眼、适度注视观察者，并可随测试语音张嘴；实时对话、记忆与人格配置随后接入。
- 空间层继续管理实际画布、眼位、倾角和离轴投影；角色进入同一三维坐标与视图/深度体系。优先评估当前 PlayCanvas 的角色适配器，不以独立网页、视频或二维浮层代替空间集成。
- 观察者眼位驱动相机；角色控制器负责骨骼、表情、注视与动作；语音层提供文本、音频和可用的时间信息。三者职责独立，默认不把观察者头动复制成角色的动作。
- 校准变换使用动画层之外的包装节点：`desk → personRoot → calibrationRoot → animatedAvatar`。展示尺度与脚底基准来自固定参考姿态或声明的脚点；动画期间不反复按变化的包围盒缩放或落地。
- VRM 适配需明确处理实际模型使用的 humanoid、expressions、lookAt、MToon、springBone 与约束。普通 GLB 加载成功不能等同于完整 VRM 支持。格式依据：[VRM 1.0](https://vrm.dev/en/vrm1/)。
- 对话后端可替换，Eidolon 为参考接入对象，语音服务按配置选择。以角色收到的播放音频驱动说话状态；音量驱动张嘴应标注为近似口型，准确口型另行核实音素/viseme 时间轴。静态 PLY/SOG 不自动获得骨骼、表情和口型能力。
- 麦克风与网络对话由独立操作启用；关闭后释放音频节点、麦克风流和连接。角色切换须取消晚到导入并释放动画、材质、纹理和物理更新资源；停用语音后保留静默展示。

## 2026-11-14：独立 Netlify 站点的移动端、动作和语音增量

本节约束 `metaflow-viewer/experiments/desktop-companion/`，来自现有 Netlify 的已记录 SHA-256 源码快照；它是独立 Three.js + three-vrm 应用。上方旧 PlayCanvas 混合原型的 40/48 项结果不自动适用于该站点。本轮也不把独立 VRM 网站表述为 SuperSplat Viewer 已集成。

### 移动显示

- iPhone 小屏、6.1 英寸参考、大屏、iPad mini 8.3 英寸和其他小平板配置。配置只能作为近似起点，必须测量可见画布并确认，不能按 User-Agent 推断精确机型。
- mini 的参考尺寸来自 [Apple 121456](https://support.apple.com/zh-cn/121456) 的 1488 × 2266、326 ppi；iPhone 6.1 英寸参考来自 [Apple 111872](https://support.apple.com/zh-cn/111872) 的 1170 × 2532、460 ppi。其他屏幕档位不冒充某一机型的实测毫米值。
- 横竖屏变化暂停跟踪、复核宽度和摄像头所在边；可继承可信的尺量 cm/CSS-pixel，但眼位/镜头确认必须重新进行。虚拟键盘引起的可视区变化不等同于屏幕旋转。
- 触控按钮至少 44px，编辑控件采用 16px 字体；小屏/横屏控制面板可滚动。打开动作区不自动聚焦文本框，避免无意弹起键盘。双指缩放只作用于模型检查视图。
- 首轮最大渲染像素比：手机 1.25、平板 1.5、桌面 1.75；属于预设预算，不是性能保证。

### 动作与声音

- 招手、点头、摇头、鞠躬均为有限时长程序化动作，带平滑进入/退出和显式停止；不宣称是花店原始动作库。动作只更新角色骨骼与表情，不修改观察相机。
- 系统朗读支持 1–500 字、声音选择、语速和音量；平台 API 在原始点击内调用。仅真实 onstart 后进入说话状态；系统朗读口型是演示近似，不能标为原角色声线、音素同步或 AI 对话。
- 本地音频限制 30 MiB；原始点击内启动 AudioContext 和媒体播放，依据实际分析器幅度更新近似口型；暂停、缓冲、错误、停止时闭嘴。文件不上传，默认不使用麦克风。
- 切换角色、隐藏、卸载时停止当前语音，断开音频节点、关闭上下文并释放 blob URL；旧会话的晚到回调不能重新启用口型或说话状态。
