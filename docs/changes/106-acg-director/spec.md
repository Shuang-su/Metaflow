# MF-106 · ACG Director 线上实验入口

状态：限定ACG实验入口已上线5.21.6，继续验收剩余动画、浏览器及严格画质；关联 [MF-106](https://github.com/Shuang-su/Metaflow/issues/106)、[MF-62](https://github.com/Shuang-su/Metaflow/issues/62)。本 Spec 是 MF-62 摄影候选在限定 ACG 入口的产品化授权，不提升其他实验成熟度。

- 公开接口仅为已发布 ACG 单文件 SOG/PLY 主路由或别名追加 `/director`。索引动态判断格式；流式、未知和非 ACG 返回具体说明。
- 主体、声明的环境、JSON 设置全部准备后开放摄影；环境失败必须可重试，不呈现完整加载状态。源文件、资源索引字段、Editor 和 Viewer SDK 不变。
- 同标签页、同资源及素材引用、30 分钟内的 Viewer 实际显示 position/target 优先；失败读取 JSON camera 或 cameras[0].initial。无合法机位报错，不以包围盒代替。Director 默认投影独立，target 作为 MF 焦点。
- 保留摄影控制、原始对照、画幅、撤销、本地兴趣点/Compose、同场景视频时间轴、转场和文件输出。移除 Studio、工程系统、素材库、账号、在线服务、Frame/设备及装饰。背景来自资源设置。
- 独立 package 使用 PlayCanvas 2.22.4、SuperSplat 3.4.2 固定来源、splat-transform 3.6.4；全精度圆孔径四样本交互，静止 120ms 后至 128/256/512。输出固定完整目标，不降低质量。WebGPU/浮点/编码能力不满足时明确报错。
- 公开界面沿用已验证候选 `209cd56c` 的组件结构、内联摄影条、Operator/Compose、时间轴与交互动画，不以新的通用弹层替代。保留限定单资源范围；样式按候选状态实现，图标使用 Lucide ISC，字体仅从可核验的 OFL 上游取得，不发布参考站整包 CSS、专有 SVG 或设备模型。
- 2026-10-05 用户修正：顶部去掉资源名及“Director 实验版”两行，直接复用 Viewer 的正式品牌矢量资产（现使用保持原始相对比例的 `metaflow.svg` 组合字标），右侧为带 padding 与圆角底色的 `beta`。资源名仍用于导出文件名。

## 2026-10-09 调整反馈修订

用户明确要求重新考虑调整阶段的 Fast 模式。公开摄影在正在调整相机、光圈或手动对焦距离时使用高精度高斯扩散预览，红色离焦参考继续由独立清晰几何生成。反馈显示“调整预览”；释放或取消后恢复四样本圆孔径起步、静止120ms后的128／256／512渐进收敛。该修订取代上文操作中只用四样本圆孔径的限定，成片算法和最终采样不变。

Fast不混入孔径累积、不保存为已收敛缓存、不进入照片或视频。输出强制清除调整、原图与红色辅助状态。内部引擎辅助帧使用独立离屏表面，最终合成器负责可见画布。测试必须分别记录持续输入响应、松手后的模型切换观感、完整采样输出及取消恢复；不能把高斯近似的速度收益称为圆孔径物理一致性。

## 2026-10-09 持续收尾验收

按用户要求继续修正具体差异，直到本次限定摄影范围的功能、视觉和运动过程都有逐项证据。新增受控诊断：相差0.003单位的透明遮挡层与10万单位远景同时存在时，排序必须遵循实际浮点深度，不能因全场景范围量化成同一档。摄影路径继续复用上游GPU radix排序；正深度按浮点位模式排序，同深度按固定entry ID稳定排序。上游原生路径保留原始格式作对照。

光学检查分别登记排序、尾部覆盖、孔径积分、颜色和资产自身缺陷；受控平面使用独立薄透镜光线参照。不得将扫描数据中本来缺失的面、发丝或残影列成可以通过增加采样恢复的实现项。逐状态验收限定于公开实际保留的控件及现有浏览器，已排除功能和未运行设备不充作已完成。

## 2026-10-09 启动恢复

生产复查中一次动态摄影入口获取失败，普通刷新后恢复；原始网络原因未证实。限定兼容修正：仅对网络类动态导入错误采用100/300/900ms退避和新模块URL，最多四次，不重试语法、执行或GPU能力错误。预算耗尽后显示可操作的重试和对应资源Viewer返回入口。Viewer及SDK独立启动不改变；摄影模型、采样、素材和相机交接不改变。使用实际浏览器的首次503及持续503验证，不以单元测试或刷新成功替代恢复验收。

## 2026-10-09 图形设备选择兼容修正

生产域名及上一版部署在当前浏览器曾出现设备20秒超时，入口资源获取正常。原生`requestAdapter({powerPreference:'high-performance'})`也曾超时，默认请求及独立GPU提交成功；本地去掉提示、再恢复提示均能128收敛，不能据此声称电源提示是唯一根因。

兼容修正使用浏览器默认适配器策略，不指定高性能电源偏好；继续限定WebGPU，并保留RGBA32F、编码和浮点能力检查。该提示不决定精度，不改变孔径、模型点数、分辨率和成片采样。只有最终部署实际摄影与输出成功才能记录交付；设备选择异常与HTTP可用性分别记录。

用户关闭低电量模式后，仍要求该模式下可以查看。页面不检测电源模式或据此禁止摄影。原20秒初始化期限改为非致命的慢启动提示，同一请求可以继续完成；90秒仍无响应时提供具体错误及重试／Viewer出口。页面离开和重试通过内部取消信号放弃旧任务，迟到设备释放，不再回写新界面；模型加载结束也检查取消。没有真实低电量模式渲染证据前不登记该环境通过，单元模拟只证明慢响应及资源生命周期处理。

运行中的设备丢失由共享监听立即报告，即使当前画面已收敛且没有新输入，也不能继续显示为正常就绪。设备重建重新加载同一资源，保留工作机位、对焦、光圈、视频镜头、机位关键帧、撤销历史及本机输出设置；只在资源身份和声明素材引用相同时恢复，不把旧编辑套到其他素材。普通可恢复渲染错误继续重试当前画面。公开接口、资源索引及工程格式不变。

## 2026-10-05 输入反馈与上线修正

沿用候选摄影组件；修复透明 header 阻断 Operator/Compose 命中。AF/MF 点击对焦提示及渐进/收敛反馈在取景框外，比例菜单在数字前显示真实宽高形状；手动距离和 ƒ 图标对齐已固定来源尺寸。原图对比使用自有分栏符号，仅切换预览，不改变摄影参数/历史。

光圈操作期间绘制独立清晰几何的连续离焦红色辅助通道，结束、取消及指针捕获丢失后清除；辅助和原图对比均不进入孔径累积、照片或视频。完整摄影状态、场景版本、尺寸和采样目标一致时复用已收敛 GPU 浮点画面；缓存最多两帧且预算 128 MiB，场景/机位/焦点/光圈/画幅/目标变化不误用旧画面，销毁释放。超预算预览正常重新渲染，不降低成片质量。

按本轮明确授权，全部修正通过定向与实际页面/输出验证后以兼容 PATCH 经 PR、预览和生产部署上线，回读版本、SHA 和结果。
