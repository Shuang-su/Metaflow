# MF-106 · ACG Director 线上实验入口

状态：实施中；关联 [MF-106](https://github.com/Shuang-su/Metaflow/issues/106)、[MF-62](https://github.com/Shuang-su/Metaflow/issues/62)。本 Spec 是 MF-62 摄影候选在限定 ACG 入口的产品化授权，不提升其他实验成熟度。

- 公开接口仅为已发布 ACG 单文件 SOG/PLY 主路由或别名追加 `/director`。索引动态判断格式；流式、未知和非 ACG 返回具体说明。
- 主体、声明的环境、JSON 设置全部准备后开放摄影；环境失败必须可重试，不呈现完整加载状态。源文件、资源索引字段、Editor 和 Viewer SDK 不变。
- 同标签页、同资源及素材引用、30 分钟内的 Viewer 实际显示 position/target 优先；失败读取 JSON camera 或 cameras[0].initial。无合法机位报错，不以包围盒代替。Director 默认投影独立，target 作为 MF 焦点。
- 保留摄影控制、原始对照、画幅、撤销、本地兴趣点/Compose、同场景视频时间轴、转场和文件输出。移除 Studio、工程系统、素材库、账号、在线服务、Frame/设备及装饰。背景来自资源设置。
- 独立 package 使用 PlayCanvas 2.22.4、SuperSplat 3.4.2 固定来源、splat-transform 3.6.4；全精度圆孔径四样本交互，静止 120ms 后至 128/256/512。输出固定完整目标，不降低质量。WebGPU/浮点/编码能力不满足时明确报错。
- 公开界面沿用已验证候选 `209cd56c` 的组件结构、内联摄影条、Operator/Compose、时间轴与交互动画，不以新的通用弹层替代。保留限定单资源范围；样式按候选状态实现，图标使用 Lucide ISC，字体仅从可核验的 OFL 上游取得，不发布参考站整包 CSS、专有 SVG 或设备模型。
- 2026-10-05 用户修正：顶部去掉资源名及“Director 实验版”两行，直接复用 Viewer 的正式品牌矢量资产（现使用保持原始相对比例的 `metaflow.svg` 组合字标），右侧为带 padding 与圆角底色的 `beta`。资源名仍用于导出文件名。

## 2026-10-05 输入反馈与上线修正

沿用候选摄影组件；修复透明 header 阻断 Operator/Compose 命中。AF/MF 点击对焦提示及渐进/收敛反馈在取景框外，比例菜单在数字前显示真实宽高形状；手动距离和 ƒ 图标对齐已固定来源尺寸。原图对比使用自有分栏符号，仅切换预览，不改变摄影参数/历史。

光圈操作期间绘制独立清晰几何的连续离焦红色辅助通道，结束、取消及指针捕获丢失后清除；辅助和原图对比均不进入孔径累积、照片或视频。完整摄影状态、场景版本、尺寸和采样目标一致时复用已收敛 GPU 浮点画面；缓存最多两帧且预算 128 MiB，场景/机位/焦点/光圈/画幅/目标变化不误用旧画面，销毁释放。超预算预览正常重新渲染，不降低成片质量。

按本轮明确授权，全部修正通过定向与实际页面/输出验证后以兼容 PATCH 经 PR、预览和生产部署上线，回读版本、SHA 和结果。

## 2026-10-08 发布前交互修正

新增用户标注保持同一摄影范围：跨紧凑布局断点必须关闭旧菜单并清除未完成拖动，Operator 恢复到当前布局且可继续操作。对照当日实际 ui.camera 的 AF/MF 按压回弹与即时文字切换、透明底色/黄色 hover、状态提示，以及展开读数的字体；不继续沿用未经验证的文字模糊缩放。来源新增归档独立于9月来源，不混用未观察参数。

继续核对 XYZ 的圆弧与30根刻度一起悬停缩放、PHOTO/VIDEO 的主题色反馈、点击对焦框的中心缩放，以及 Operator 内外 padding、文字和图标尺寸。菜单退出期间仍在场的滑杆必须先释放指针捕获并清空待提交值，再撤销手势，避免退出动画期间的输入覆盖已恢复状态。
