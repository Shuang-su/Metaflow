# 图标参考

部分线性操作图标按线上 Studio 使用的 Lucide 路径对齐，采用 ISC 许可，见 `Lucide-LICENSE.txt`。Orbit、Fly、取景与重置复用 Editor 自带 SVG。

# Studio brand assets

- `metaflow_logo.svg` and `metaflow_word.svg`: exact copies of the existing Metaflow Viewer assets at `metaflow-viewer/src/assets/`, used without altering their shapes or proportions.
- `Inter.ttf`: Inter variable font from the official Google Fonts repository, https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf, retrieved 2026-09-06. Redistributed under the included SIL Open Font License (`Inter-OFL.txt`).
- Studio-only Rollup copying keeps these assets and font separate from the ordinary Editor bundle.
