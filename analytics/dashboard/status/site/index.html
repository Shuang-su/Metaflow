如何理解状态

“入口可达”说明 HTTPS 请求成功；“数据已更新”说明汇总快照也在有效时间内。业务汇总超过 30 分钟、服务器采样超过 3 分钟会单独显示延迟。

GitHub 定时任务可能延迟。超过 30 分钟没有完成监测，整页显示“状态未知”，不会沿用绿色正常状态。

数据接收接口仅使用 OPTIONS 探测，不会生成访问埋点。公开看板尚未切换时会明确标记“准备中”。
