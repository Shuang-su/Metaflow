# 桌面高斯人像 · MF-165 实验

这是 MetaFlow 的独立实验原型：利用离轴投影，让倾斜平板里的高斯人像看起来立在水平桌面上。

**当前为 Draft，尚未完成浏览器视觉验收或 iPad 实机验收，未合并/部署到生产 Viewer。** 自动测试验证了几何、固定版本引擎的相机矩阵和摄像头生命周期；它们不等于真实光学效果或帧率验证。

## 启动

在本目录运行：

```sh
npm ci --ignore-scripts
npm test
npm run serve
```

浏览器打开 `http://127.0.0.1:4176/`。开发服务器仅监听本机，静态文件范围限制在本实验目录；不包含生产 Viewer 的构建或部署步骤。端口可以通过 `PORT` 设置。

在实体 iPad 上运行需要把本实验及其固定依赖放到可访问的 HTTPS 测试站点；本次没有创建这样的站点。普通局域网 HTTP 可能不能请求摄像头。应由项目现有发布流程提供 HTTPS 预览，不要为测试绕过证书警告。

## 使用

1. 初始载入的是本项目独立生成的 **7,600 点合成高斯校准人形**，不是人像扫描成果，也不是原作素材。
2. 打开自己的单文件 PLY/SOG 或 VRM 角色，或者明确输入已有 HTTPS 文件链接。本地文件不上传；首轮限制单文件 150 MiB，不支持 loose SOG 或 streamed LOD。
   - **VRM 角色**：支持 VRM 1.0 格式，自动呈现待机动画、眨眼、注视和音频驱动的口型。
3. 在全屏后的实际画布上测量宽度。填写支架倾角、眼睛相对屏幕中心的左右/高低位置、到屏幕平面的垂直距离。角度是屏幕对桌面的夹角，平放为 0°、竖立为 90°。
4. 调整源模型坐标、展示高度、前后位置、朝向和脚底微调。MetaFlow 现有人像通常使用 `Z 翻转 180°`；不同资产以实际效果为准。包围盒自动落地可能受漂浮杂点影响，必要时应先清理模型。
5. 用桌面颜色、木纹/纯色/网格和软接触阴影匹配现场。阴影是视觉辅助，未实现真实光照重建。
6. 在手动位置正确后，可点击开启前摄。保持一个人正对前摄片刻建立参考；长时间丢脸、突变或画面尺寸变化后点击「重新居中」。关闭、页面隐藏或离开都会停止采集。
7. 点击「进入展示」隐藏控制；「退出展示 · 调整」或 Escape 恢复。窗口/横竖屏变化后重新核对物理宽度与眼位。

## 技术与数据边界

- 引擎固定为 **PlayCanvas 2.23.0**，与当前 MetaFlow Viewer 5.22.0 一致。
- VRM 角色使用 **Three.js 0.170.0** 和 **@pixiv/three-vrm 3.1.4**，共享 WebGL 上下文，在 PlayCanvas 渲染后合成。
- 相机实体位置、垂直 FOV、aspect 和 `projectionOffset` 同步更新。相机平行屏幕，不用 `lookAt` 或 CSS 倾斜代替离轴投影。
- 桌面、人物和脚底阴影共享由倾角决定的根节点。首轮只辅助前后倾角；不提供完整重力向量、屏幕自动识别或场景自动重建。
- 跟踪依赖固定 **MediaPipe Tasks Vision 0.10.32**，模型是官方 `face_landmarker/float16/1`。首次主动开启会下载模型与加载本地 WASM；没有上传视频、关键点或轨迹的代码，不加载产品分析/回放。
- 追踪使用主线程 CPU 推理，最高 15 Hz；不是 Worker 实现，也不是实测性能承诺。平均瞳距假设为 63 mm，普通前摄只能估计校准后的相对眼位，转头会影响尺度。
- `numFaces:1` 面向单观察者环境，不能可靠识别两个持续同框的人是否切换目标。它不做身份识别；长丢脸和明显突变后的锁定只能减少视角跳转。
- 普通屏幕是单观察点错觉。人物不能遮挡实体边框，不向双眼或多人分别发送不同画面。
- **VRM 动画**：待机呼吸（15/分钟）、随机眨眼（平均 3 秒）、注视观察者（平滑插值）。口型由测试音频音量驱动，是近似动作，不是音素对齐。
- **测试音频**：本地合成的语音类波形，用于演示口型；不连接实时对话或外部语音服务。真实对话集成（Eidolon/Fish Audio）留作未来扩展。

## VRM 角色与授权

本实验支持用户提供的 VRM 1.0 角色文件。**不随代码分发任何角色模型。**

- **LAPLACE Milky Green（明前奶绿）** 和 **Persona 示例角色** 仅作为参考设计对象，未包含在代码仓库中。
  - 来源：[LAPLACE Persona VRM](https://laplace.live/persona/vrm)
  - 授权限制：[Persona License 第 4 节](https://laplace.live/persona/license) 要求非商业使用和署名。
  - 用户如需使用这些角色，需自行获取并遵守其授权条款。
- **测试 VRM**：用户可使用自己创建或获得明确授权的 VRM 文件，或使用公开的 permissive license VRM 示例（如 VRM Consortium 的 CC0/CC-BY 示例）。
- **元数据保留**：VRM 文件内嵌的作者、授权和署名信息在导入后保留。商业发布需使用完全授权的角色与声音。

本实验不实现真实对话或连接外部语音服务；测试音频为本地合成波形。Eidolon 和 Fish Audio 的集成留作未来产品扩展。

## 已验证与待验收

`npm test`：几何、引擎投影、摄像头生命周期和资源加载测试。覆盖屏幕四角/中心不变、前后景视差、横竖比例、实际安装引擎投影 setter、倾角与脚点共面、无效输入、摄像头启停竞争、权限拒绝、后摄拒绝、丢脸、页面隐藏、资源流大小上限、取消/超时、同 URL 重试和晚到资源释放。所有 `.mjs` 语法检查通过。

**VRM 集成**：VRM 加载器、动画控制器和音频分析器已实现，待浏览器环境验证材质渲染、表情、骨骼和口型同步。自动化测试覆盖流控制和取消；真实 VRM 的视觉效果、表情可用性和 iPad 性能需实机检查。

独立审查另以真实 PlayCanvas `ResourceLoader / AssetRegistry / Asset` 和测试资源复核同 URL 两次加载：解析两次、资源对象独立，卸载第一份不会销毁第二份。该检查不涉及 GPU 或真实人像渲染。

当前环境曾尝试本地 Chromium 与云浏览器验证：本地 Chromium 因进程 socket 权限限制未能启动，云浏览器无法访问本地开发端口，补装官方 headless shell 的下载未得到有效归档。因此 **未获得真实渲染截图、真实 SOG 导入成功或 iPad 追踪性能证据**；本轮不能写成视觉 QA 通过。

正式集成前还需完成：真实人像视觉/失败重试、窄屏/全屏/旋转、目标 iPad Safari/主屏幕应用、真人追踪与持续运行、WebGPU/LOD、普通相机/XR/截图交接。产品 Issue 保持 Open。
