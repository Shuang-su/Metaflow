屏幕

量三维画布，不是整个显示器。也可调节此项，让下方校准尺与实体尺的标示长度相等。

先量准画布，在下一节填写镜头位置，再点击确认。确认前可静默识别，但场景不跟随；诊断取景需手动开启。

02

面部 / 头部追踪

允许相机后，浏览器才可能显示完整设备名称。

Mac 校准前

关闭“人物居中 / Center Stage”和自动构图，固定相机缩放。使用朝向自己、靠近当前屏幕的摄像头；窗口模式下请选“自定义镜头位置”，相对可见画布中心量取镜头偏移。

权限被拒时，检查 Safari 的“设置 → 网站 → 摄像头”，以及 macOS“系统设置 → 隐私与安全性 → 摄像头”。

沿垂直于屏幕的方向测量距离。设备侧放时按自然坐姿校准，不必持续看镜头。单目头部位置是近似估计；完全背脸或被遮挡时会暂停。

精确调整镜头与眼位

以可见三维画布中心为原点，向右、向上为正。窗口移动或切换显示器后重新测量。

03

观察方式

桌面窗口随眼位改变透视；模型检查使用普通透视，方便核对人物外观。

先点击画面。拖动 / 方向键调整；R 复位。模型检查中可用滚轮或触控板缩放。
